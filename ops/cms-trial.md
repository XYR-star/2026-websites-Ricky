# Decap 游记试用

正式切换说明见 [cms-production.md](./cms-production.md)。正式启用后，旧试用入口跳转至 `/admin/`；本文件保留试用阶段的配置说明。

试用后台在预览分支的 `/cms-trial/index.html`。文章保存到 GitHub 草稿分支，发布到 `decap-preview`。通过 Vercel 的分支地址查看已发布的游记。

## 写作和素材

1. 打开游记，填写标题、简介和正文。封面和正文图片的选图按钮都打开这篇游记的素材页。
2. 上传原图，或选择列表里已有的图。「查看图片」只在点击后加载该原图。上传目录是 `cms/travel/<文章素材目录 ID>/`。对象名用随机 ID，上传时保留原文件名供列表显示。建议先保存含素材目录 ID 的草稿，再换设备继续写。
3. 用右侧预览看封面和正文。保存草稿后再走审核和发布。发布前检查草稿 PR 的文件差异，发现站点配置被夹带时先处理 PR。

仅授权的 Cloudflare Access 用户可以访问上传器和素材列表。上传后的对象具有公开链接。草稿分支也位于公开 GitHub 仓库，请只使用可以公开的文字和图片。保留原图也会保留其中的元数据。

## 上传 Worker 更新

在 Cloudflare 编辑现有的 `ricky-media-upload`，使用同目录的 `r2-media-worker.mjs` 部署。保留 `MEDIA` 绑定和覆盖所有流量的 Access 保护。新 Worker 兼容原来的平铺上传路径和旧图片 URL。

如要切换素材域名，先在 `ricky-site-media` 桶设置中绑定 `assets.heyrickishere.com`。用一个已知对象确认 HTTPS 读取成功，再为 Worker 添加普通变量 `MEDIA_PUBLIC_BASE=https://assets.heyrickishere.com`。暂时保留旧的 `r2.dev` 访问，让现有文章链接继续有效。若需回退，可删去此变量，之后的新上传恢复使用原域名。

自定义域在 R2 显示为有效后，进入 Worker 的「设置 → 变量和机密」添加上述文本变量，并保存部署。重新打开素材窗口后，新增和复用图片都会返回新域名的链接。图片文件和文章素材目录不变。现有文章中已保存的链接需要另行替换；试用游记的封面及正文图片已切换到自定义域。

正文图片在生成页面时设置延迟加载和异步解码，封面优先加载。原图不会压缩或转码。只有单独占一段的图片会转换为图片组；与文字混排的图片保留原段落。

上传窗口的「旧素材」只列出同一素材桶早期存放在 `cms/` 下、尚未按文章分组的图片。选择旧图会复用原链接，新上传仍归入当前文章。其他存储桶的素材需按需迁入。

素材库没有删除操作。清理前需要核对已发布文章、草稿和共用图片的引用。

## 正式上线前

为生产单独配置 Decap 发布目标和 Worker 回传地址。GitHub 草稿分支名不包含发布目标，避免在同一仓库同时维护同一篇文章的试用和生产草稿。试用编辑器的发布前检查有助于拦截误操作。生产仍应通过 GitHub 分支规则要求正常 PR 和内容检查，发布应用不设绕过权限。
